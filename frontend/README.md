# Career Transition Assistant – frontend

React/Vite-frontend for Career Transition Assistant. Se [prosjektets README](../README.md) for fulle oppstartsinstruksjoner for frontend og backend sammen.

## Oppstart

```bash
npm install
npm run dev
```

Appen kjører da på `http://localhost:5173` og forventer at backenden kjører på `http://127.0.0.1:8000` (se `.env.example` for å endre adressen via `VITE_API_BASE_URL`).

## Andre kommandoer

```bash
npm test      # kjører automatiserte tester (Vitest)
npm run lint  # kjører ESLint
npm run build # produksjonsbygg
```
